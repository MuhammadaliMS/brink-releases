# Brink for macOS

Your trackpad has edges. Brink turns them into controls: slide the right edge for volume, the left edge for brightness, the top edge for the keyboard light, and swipe the bottom edge to skip songs. It lives in the menu bar and shows the same on-screen display as the keys.
